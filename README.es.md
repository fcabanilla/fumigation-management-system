# 🌾 Fumig App - Sistema de Gestión de Fumigación Agrícola# 🌾 Fumig App - Sistema Integral de Gestión de Fumigaciones Agrícolas



Una aplicación React SPA moderna para la gestión de fumigación agrícola con autenticación del lado del cliente y persistencia de almacenamiento del navegador. La aplicación sigue una arquitectura simple de dos páginas diseñada para demostración y gestión de flujos de trabajo agrícolas.Una aplicación web moderna y profesional desarrollada en React para la gestión completa de fumigaciones agrícolas, diseñada para optimizar los procesos de tratamiento de cultivos y maximizar la eficiencia operativa.



## 🎯 Visión del Producto## 🎯 Visión del Producto



Fumig App es una solución digital integral que optimiza los procesos de fumigación agrícola, desde la planificación hasta la ejecución y análisis, proporcionando a agricultores y profesionales agrícolas herramientas modernas para una gestión efectiva de cultivos.Fumig App es una solución tecnológica integral que digitaliza y optimiza todos los procesos relacionados con la fumigación agrícola, desde la planificación hasta el análisis de resultados, proporcionando herramientas avanzadas para la toma de decisiones basada en datos.

### Errores de instalación de dependencias

```bash
# Limpiar cache y reinstalar
npm cache clean --force
rm -rf node_modules package-lock.json
npm cache clean --force
npm install

# En Windows PowerShell
Remove-Item -Recurse -Force node_modules, package-lock.json
npm cache clean --force
npm install
```

### Fallos en tests

```bash
# Ejecutar en modo verbose
npm test -- --verbose --no-cache

# Regenerar snapshots si es necesario
npm test -- --updateSnapshot
```

### Problemas de memoria durante build

```bash
# Aumentar memoria disponible para Node.js
set NODE_OPTIONS=--max-old-space_size=4096 && npm run build

# En Linux/Mac
NODE_OPTIONS=--max-old-space_size=4096 npm run build
```

### Errores de permisos en Windows

```bash
# Ejecutar PowerShell como administrador
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
npm install
```
